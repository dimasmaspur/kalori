# Kalori

PWA pribadi untuk catat kalori: foto/teks → Gemini → kkal & makro. Data tersimpan di HP (localStorage), tanpa server.

- Jalankan lokal: `python3 -m http.server 5173` lalu buka http://localhost:5173
- API key: ambil gratis di https://aistudio.google.com → Get API key, isi di tab Pengaturan.
- Pasang di Android: buka URL HTTPS-nya di Chrome → menu ⋮ → "Tambahkan ke layar utama" / "Instal aplikasi".
